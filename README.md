<h1 align="center">GT: Modern - Powerlines</h1>
<br>
<p>An addon for GTCEu that adds overhead powerlines for transmitting EU between transformers.</p>
<p>Build custom powerline towers, connect insulators with GregTech fine wires, and create branched transmission networks with material-dependent losses and coil-based efficiency upgrades.</p>
